## 채팅에게 주는 지시문 (이 부분부터 붙여넣기)

너는 나와 함께 모바일 앱 기획을 다듬는 파트너야. 아래는 지금까지 정리한 1-Pager와
확정된 결정, 그리고 열려 있는 질문들이야. 새 기능을 늘리는 방향이 아니라 **코어를
날카롭게** 하는 방향으로, 근거를 들어 냉정하게 조언해줘. 내가 문장을 고쳐달라고 하면
1-Pager 형식을 유지한 채 해당 칸만 다시 써줘.

**한 줄 제품 정의:** 고양이가 내 하루(걷기 + 폰 터치)를 대신 살아주는 교실에서,
말없이 기척(쓰다듬)을 주고받고 우연한 겹침(같이 깨어있음)을 발견하는 연결 앱.
봉고캣의 '입력 → 즉각 반응' × 소셜(친구 아바타가 한 화면에).

**절대 원칙 (스코프 가드레일):**
- **봉고캣 수준의 단순함.** 게임 시스템(수집·성장·가챠·랭킹·도전)을 얹지 않는다.
  파는 재미는 '반응의 손맛 + 함께 있음'이지 게임 깊이가 아니다.
- **무언(無言) 원칙.** 채팅·댓글·읽음 확인 없음. 말이 생기는 순간 카톡과 경쟁한다.
- **기척이지 감시가 아니다.** 정확한 폰 사용 시간·횟수·위치는 공유하지 않는다.
- 유지(리텐션)는 게임성이 아니라 전적으로 소셜에서 온다. 시들해지면 기능을 더하지 말 것.

**확정된 결정:**
- 활동 = **걸음 + 터치**. 보상 루프(걸음·터치 → 별가루 → 모자/털색 꾸미기)는
  **가볍게 유지**. 단 대사 확률 편집기는 프리셋으로 단순화, 점수 랭킹은 '기척판
  (지금 상태)'으로 대체.
- 인증은 익명(닉네임만), 초대는 6자리 코드, 한 교실 최대 8명.
- 겹침은 실시간 presence가 필요 → Supabase Realtime을 붙이는 즉시 fast-follow.

**현재 구현 상태 (프로토타입 존재):** React Native(Expo) 1인용 앱이 이미 동작한다 —
걸음·터치 반응 고양이(교실 무대), 시계 모드, 별가루 보상·꾸미기, 대사, 쓰다듬 기록,
기척판. **친구 연동(Supabase)은 아직 미구현** — 지금은 데모 친구로 시뮬레이션 중.
따라서 지금 가장 큰 미검증 조각은 '진짜 친구와의 연결'.

**열려 있는 질문 (여기서 이어서 논의하고 싶은 것):**
1. Wow의 '오늘의 나' 카드(하루 요약 공유 이미지)를 v1에 넣을까, 뒤로 미룰까?
2. 겹침의 정의(시간대·활동 조건)를 어떻게 잡아야 특별함이 유지될까?
3. presence '지금 접속 중' 신호를 옵트인으로 둘 때의 UX와 프라이버시 문구.
4. 콜드스타트용 NPC(선생님 고양이) 1마리를 어떻게 자연스럽게 둘까?
5. 첫 과금 지점(별가루 팩 vs 시즌 한정)과 가격 감각.

## 1-Pager (현재 버전)

### 기본 정보
- 작성자: 김진선
- 서비스 이름 (가칭): 고양이 교실 (Cat Class)
- 한 줄 소개: 고양이가 내 하루(걷고, 폰을 만지는)를 대신 살아주는 교실에서,
  말없이 기척을 남기고 우연한 겹침을 발견하는 연결 앱.

### 0. 핵심 문법 (제품의 새로운 지점)

**기척 프로토콜 — 답장 의무를 구조적으로 제거한 상호작용 (4규칙):**
1. 무언: 텍스트 입력이 아예 없다.
2. 비대칭: 쓰다듬은 받은 사람에게만 보인다(공개 피드·좋아요 없음).
3. 무영수증: 읽음 확인이 없다 — 보낸 사람은 상대가 봤는지 모른다(카톡 "1"의 반대).
4. 무의무: 되쓰다듬어도 '누구에 대한 답'인지 표시 안 됨 → 안 해도 미안하지 않다.
→ 주는 쪽도 받는 쪽도 부담이 0인 안부 채널.

**겹침 — 설계할 수 없는 순간을 심장으로:** 두 사람이 동시에 같은 상태(둘 다 새벽에
폰, 둘 다 걷는 중)일 때 고양이들이 전용 장면·대사를 만든다. 기다려야만 나와서 희소하고,
마주침 일지로 쌓이며, 캡처가 단톡방 바이럴이 된다.

**게임 관점 — 봉고캣 수준의 반응 장난감(스코프 원칙):** 파는 재미 = 감각(반응 손맛)·
함께함(기척·겹침)·표현(가벼운 꾸미기)·힐링(방치·상시 표면). 안 파는 것 = 수집·성장·
도전·서사. 유지는 소셜에서 온다.

### 1. 고객의 문제
생활권이 갈라진 친구 사이엔 '문득 친구 생각나는 순간'이 자주 온다(밤에 폰 보다가,
같이 가던 가게 앞에서). 그 순간 카톡을 열었다 "새벽인데, 용건도 없는데" 하고 닫는다 —
보내면 상대에게 답장 의무("1" 지우기)를 지우니까. 이 '연락할 정도는 아닌 궁금함'이
버려진다. 강도는 낮지만 빈도는 높아 쌓이면 "우리 요즘 연락 안 하네"가 된다. 기존 수단은
틀린 게 아니라 이 작은 궁금함엔 한 층 무겁다(단톡방=말 시작해야, 스토리=올리는 사람만,
젠리=과함). 필요한 건 '말 걸기'보다 가볍고 '올리기'보다 노력 안 드는 한 층 아래 채널.

### 2. 타겟 유저
졸업·취업·이사로 생활권이 갈라진 20대 중반~30대 초반 친구 그룹(3~8명). 단톡방은 몇 주에
한 번 울리지만 서로 궁금한 사이 — 그중 "우리 이거 하자"고 판 까는 주도자 1명이 최초 타겟.
(획득 단위는 개인이 아니라 그룹.)

### 3. Recurring Value (한 문장)
"'쟤 지금 뭐 하나'와 '누가 내 생각을 했나'가 궁금할 때마다 교실을 연다." — 열 때마다
친구의 지금/내게 온 기척/새 겹침 중 하나는 있다. 안부 비용이 '말 걸기'에서 '열어보기'로.

### 4. Wow Moment
- **(0) 반응의 손맛(혼자, 즉시):** 설치 10초 뒤 걸으면 고양이가 뛰고 터치하면 필기 —
  내 하루가 캐릭터가 되는 봉고캣의 손맛. 콜드스타트는 이걸로 풀되 혼자 재미는 오래 못 감.
- **(1) 켜는 계기:** 문턱 0(회원가입 없음) + 친구가 보낸 코드(이미 한 명이 보증).
- **(2) 첫 '오!':** 코드를 넣는 순간 친구 아바타가 내 교실에서 살아 움직이고 서로 쓰다듬음.
  두 사람이 동시에 "오!" = 동시에 추천각.
- **(3) 추천 트리거:** '오늘의 나' 카드/겹침 캡처가 단톡방에 나가면 "그거 뭐야 나도".

### 5. 핵심 기능 (MVP)
**가설:** 사람들은 연결된 친구 아바타가 지금 뭘 하는지 보려고 매일 교실을 열고,
쓰다듬 한 번으로 카톡 없이 연결감을 느낀다.

**Core 3:**
1. 내 하루의 반응 고양이(+시계 모드) — 걸으면 뛰고 터치하면 필기, 조용하면 잠. 노력 0.
2. 친구 교실 + 기척 — 초대코드 참여(최대 8명), 친구 아바타 반응, 쓰다듬(나만 보는 기록).
3. 가벼운 보상·꾸미기 — 걸음+터치 → 별가루 → 모자/털색. 봉고캣 수준으로 얕게.

**안 넣을 것:** 채팅/댓글, 읽음 확인, 공개 피드·좋아요, 수집·성장·가챠·랭킹 경쟁,
대사 확률 편집기, 실시간 위치, 정확한 폰 사용 시간 공유, 현금성 리워드, 푸시(v2).
**fast-follow:** 겹침(실시간 presence 붙는 즉시).

### 6. 비즈니스 모델
별가루 팩 IAP(예: ⭐500=1,900원) + 시즌 한정 아이템 현금 전용(990원). 과금 동기 =
친구들이 보는 무대에서 내 고양이를 꾸미고 싶을 때. 차선: '별가루 받기' 직전 보상형 광고.

### 7. AARRR
- Acquisition: 주도자의 초대코드 한 줄 + 화면 캡처 공유 + 숏폼.
- Activation: 첫 친구가 들어와 서로 아바타가 처음 반응·쓰다듬는 순간. 온보딩 끝=코드 공유.
- Retention: 친구의 지금(기척판) + 쓰다듬 미확인 배지 + 시계 모드 상시 + 별가루(자정 리셋).
- Revenue: 별가루 팩 + 한정 아이템. 트리거=친구 고양이의 왕관.
- Referral: 캡처 공유 + 빈 책상이 부르는 초대 + 입장 시 양쪽 별가루.

### 부록: 약점 진단
0. 정체성 포크(게임 vs 커뮤니케이션) → 블렌드로 확정("게임 완성도로 이기지 않는다").
1. 봉고캣 수준 = 솔로 리텐션 약함(감수) → 유지는 소셜에서, 개발 1순위 친구 연동.
2. 겹침엔 실시간 presence 필요 → v1 코어로 승격(Supabase 내장이라 복잡도 제한적).
3. 겹침 빈도 튜닝이 생사 → 넓게 시작해 데이터로 조임(상수 튜닝).
4. 무영수증의 허무함 → 읽음확인 대신 '내가 남긴 기척 주간 요약'으로만 완화.
5. 프라이버시 → 기본은 활동량+마지막 활동까지, '지금'은 옵트인, 정확 시간은 영구 비공유.
6. 네트워크 의존 → 초대 전 짧게, 빈 교실은 NPC 1마리로.
7. Android 걸음 신뢰성 → iPhone 그룹부터, Health Connect는 이후.
