# 잘지냥 시작하기 — 최소 클릭 버전

> 목표: 진선님이 직접 하는 건 **가입 2번 + 붙여넣기 3개 + 명령어 2개**가 전부.
> 나머지(데이터베이스 설치, 보안 규칙, 앱 연결, 자가진단)는 스크립트가 합니다.

## A. 서버 연결 (5분)

1. **가입 + 프로젝트 만들기** — https://supabase.com → 구글로 가입 →
   **New project** (이름 아무거나, 비밀번호 만들어서 메모, 지역 **Seoul**) → 1~2분 대기
2. **자동 설치 실행** — 컴퓨터 터미널에서:

   ```bash
   cd mobile
   npm install
   npm run setup
   ```

   스크립트가 3개 값을 물어봅니다. 전부 Supabase 대시보드에서 복사:
   - **Project URL** — Project Settings(톱니) → API
   - **anon public 키** — 같은 화면
   - **DB 연결 문자열** — 상단 **Connect** 버튼 → URI 탭 (`[YOUR-PASSWORD]`를
     1번에서 만든 비밀번호로 바꿔서)

   붙여넣으면 스크립트가 테이블·보안 규칙·추첨 함수를 설치하고, 연결을 스스로
   점검한 뒤 "🎉 서버 연결 끝!"을 띄웁니다. 문제가 있으면 **어디를 클릭하면 되는지
   한국어로** 알려줘요 (예: 익명 로그인 스위치가 꺼져 있으면 바로가기 링크 출력).
   몇 번을 다시 실행해도 안전합니다.

## B. 갤럭시에 앱 설치 (10분, 대부분 대기 시간)

걸음(Health Connect) 때문에 전용 앱(APK)이 필요해요. 클라우드에서 만들어줍니다:

```bash
npm run build:android
```

- 처음 한 번 https://expo.dev 무료 가입/로그인을 물어봅니다
- 10분쯤 후 **설치 링크(QR)**가 나오면 갤럭시에서 열어 설치
- 걸음이 안 잡히면: 삼성헬스 → 설정 → **헬스 커넥트에 데이터 공유** 켜기

친구에게는 이 **APK 링크 + 초대코드**만 카톡으로 보내면 끝. 스토어 심사 없이
우리끼리만 쓰는 앱이 됩니다 (초대코드 없으면 교실에 못 들어와요).
아이폰 친구는 Expo Go 앱으로 참여 가능합니다.

## 자주 묻는 것

- **돈 나가요?** 전부 무료 티어로 충분해요. Supabase는 1주일 미사용 시 잠자기 모드가
  되는데, 대시보드에서 Restore 한 번이면 깨어납니다.
- **오프라인 모드로 되돌리려면?** `mobile/.env` 파일을 지우면 됩니다.
- **anon 키는 공개돼도 되나요?** 네 — 보안은 서버의 RLS 규칙이 지킵니다.
  단, 같은 화면의 **service_role** 키는 절대 어디에도 붙여넣지 마세요.
