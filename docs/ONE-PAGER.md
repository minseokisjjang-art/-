# 1-Pager — 고양이 교실 (Cat Class)

- 작성자: 김진선
- 서비스 이름 (가칭): **고양이 교실** (Cat Class)
- 한 줄 소개: **내 걸음과 터치에 실시간으로 반응하는 고양이를, 초대한 친구들과 한 교실에서
  함께 키우는 방치형 만보기 앱.** (봉고캣의 '입력 시각화' × 캐시워크의 '걸음 보상' × 친구)

---

## 1. 고객의 문제 (Problem)

- **누가/어떤 상황**: 매일 걷기는 해야겠는데 만보기 앱은 숫자·그래프뿐이라 3일이면 안 열게 되는
  사람. 그리고 친한 친구들과 매일 카톡을 주고받을 정도는 아니지만, 서로의 근황이
  궁금하고 "말 없이 연결되어 있는 느낌"을 원하는 사람.
- **어떤 불편**: ① 걷기의 동기가 유지되지 않는다 (숫자는 감정을 못 만든다).
  ② 친구에게 용건 없이 연락하는 건 부담스럽다 — 근황을 아는 방법이 카톡/인스타뿐인데
  둘 다 '말을 걸어야' 한다.
- **지금의 해결책**: 만보기·캐시워크(보상은 있지만 정 없는 리워드, 친구 없음),
  카톡(부담), 인스타(전시용 근황). 셋 다 "가볍고 귀여운 무언의 연결 + 걷기 동기"를 못 준다.

## 2. 타겟 유저 (Target User)

**만보 목표를 의식하는 20대 중반~30대 초반 직장인 중, 3~8명짜리 친한 친구 그룹에서
"이거 같이 하자"고 판을 까는 사람.** 다마고치·동물의 숲·봉고캣 같은 '귀여운 방치형'에
반응한 경험이 있고, 카톡 단톡방은 있지만 매일 대화하지는 않는 그룹의 주도자.
(이 1명이 초대코드로 그룹 전체를 데려온다 — 획득의 단위는 개인이 아니라 그룹이다.)

## 3. Recurring Value (꾸준히 사용할 이유)

**한 문장: "친구들의 고양이가 오늘 뭘 하고 있는지 — 즉 친구가 오늘 얼마나 움직였는지 —
궁금할 때마다 교실을 연다."**

보조 루프: 내가 걸을수록 고양이가 신나게 뛰고 포인트가 쌓여 1,000점마다 별가루를
'탭해서 받는' 순간이 하루 여러 번 생긴다 (마이크로 클레임).

## 4. Wow Moment (처음 시도해볼 이유)

**초대코드를 입력하는 순간, 친구의 고양이가 내 화면의 교실에 나타나고
친구의 오늘 걸음이 칠판 점수판에 보인다.** — "어? 너 오늘 왜 이렇게 많이 걸었어?"가
카톡 없이 일어난다.

혼자일 때의 예비 Wow: 화면을 누르고 있는 동안 고양이가 즉각 책상에 앉아 필기하는
반응성(봉고캣), 그리고 설치 직후 내 걸음 수가 곧바로 고양이의 달리기로 보이는 순간.

## 5. 핵심 기능 (MVP 범위)

**검증하려는 핵심 가설 (한 문장):**
"사람들은 친구 고양이의 오늘이 궁금해서 하루에도 몇 번씩 교실을 열고,
점수판 때문에 평소보다 더 걷는다."

**Core Features (3개):**
1. **활동 반응 고양이 + 보상 루프** — 걸음·터치에 즉각 반응하는 내 고양이,
   포인트(걸음＋상호작용) → 1,000점마다 별가루 → 꾸미기 구매.
2. **친구 교실** — 6자리 초대코드로 참여(최대 8명), 칠판 점수판에 전원의 오늘 점수,
   친구 고양이 쓰다듬기(나만 보는 기록으로 남음).
3. **시계 모드** — 화면이 꺼지지 않는 잠금화면 대용 글랜스(시계 + 걸음·포인트 +
   별가루 받기 버튼). 책상 위에 세워두는 상시 표면.

**일부러 넣지 않을 기능:** 채팅/댓글(무언의 연결이 컨셉), 실시간 위치 공유,
현금성 리워드(캐시워크와의 정면 경쟁 회피), 가챠/장터, 푸시 알림(v2로),
실시간 동기화(새로고침 시 갱신으로 충분).

## 6. 비즈니스 모델 (수익화 방안)

**별가루 소액 IAP.** 별가루는 걸어서 벌 수 있지만(1,000점=⭐10), 지름길로
**별가루 팩(예: ⭐500 = 1,900원)** 을 판다. 여기에 **시즌 한정 아이템은 현금 전용**으로
걸어 희소성을 만든다(예: 계절 모자 990원). 과금 시점 = 친구들 앞에서 내 고양이를
꾸미고 싶어지는 순간(교실이라는 무대가 과금 동기를 만든다).
정 어려우면: '별가루 받기' 직전에 보상형 광고(광고 보면 ×2) — 유저가 '기회'를 얻는 지점.

## 7. AARRR 단계별 설계

- **Acquisition(획득):** 초대코드 자체가 획득 채널 — 그룹 주도자 1명이 단톡방에 코드
  한 줄을 올리면 3~7명이 들어온다. 외부 유입은 고양이 반응(터치→필기, 걸음→달리기)
  숏폼 영상을 인스타 릴스/틱톡에.
- **Activation(활성화):** 설치 → 닉네임만 입력(회원가입 없음) → 30초 안에 내 걸음이
  고양이 달리기로 보이고 **첫 별가루를 받는다** (첫날은 낮은 문턱으로 첫 클레임 보장).
- **Retention(재사용):** ① 친구 점수판의 역전("어제 민지한테 졌다"), ② 쓰다듬 기록의
  미확인 배지, ③ 시계 모드로 책상 위에 상시 노출, ④ 자정 리셋되는 오늘의 포인트.
- **Revenue(결제):** 별가루 팩 IAP + 시즌 한정 아이템(현금 전용). 보조: 클레임 시 보상형 광고.
- **Referral(지인 추천/공유):** 교실에 빈 책상이 보인다 → "친구 초대" = 카톡으로 코드
  공유 한 번. 추천 보상: 친구가 들어오면 둘 다 별가루 지급(수치는 소액).

## 부록: 자체 약점 진단 (작성자 검토용)

1. **Recurring Value가 친구 수에 의존한다 (가장 큰 약점).** 혼자면 교실이 비어 3번 문항이
   무너진다. → 개선: 1인용 보상 루프(포인트→별가루)가 이미 자립하도록 설계됨 + 초대 전엔
   기본 NPC 고양이 1마리(선생님 고양이)로 교실을 살려둔다. 신규 기능 아님 — 지금의 데모
   친구를 1마리로 줄여 상시 캐릭터화하는 것.
2. **Wow(친구 입장)가 초대 이후에 온다 — 초대 전 이탈 위험.** → 개선: Activation에 명시한
   '첫날 낮은 클레임 문턱'(상수 1개 조정)으로 설치 30초 내 첫 보상을 보장.
3. **수익모델이 약하다 — 별가루를 무료로 벌 수 있어 지불 이유가 흐릿.** → 개선: 한정
   아이템 '현금 전용' 플래그 하나로 희소성 확보. 복잡한 이코노미 설계는 하지 않는다.
4. **Android 걸음 데이터 신뢰성 (Health Connect 미구현).** → 검증 단계는 iPhone 위주
   친구 그룹부터 시작하고, Android는 Health Connect 연동 후 확대.
5. **포지셔닝 리스크: '캐시워크보다 보상이 약한 앱'으로 읽힐 수 있다.** → 리워드 앱이
   아니라 '친구와의 무언의 연결 앱'으로 소개 문구를 고정 (마케팅 문구 문제, 기능 아님).
