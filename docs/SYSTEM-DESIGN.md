# 🐱 봉고캣 모바일 — 시스템 기획서

| 항목 | 내용 |
|---|---|
| 서비스명 | 봉고캣 모바일 (Bongo Cat Mobile) |
| 한 줄 콘셉트 | 잠금화면에서 친구들의 고양이와 함께 사는 방치형 힐링 게임 |
| 플랫폼 | 모바일 웹 (PWA — 홈 화면 설치 시 전체화면 앱) |

## 1. 서비스 개요

### 1.1 기획 배경

PC용 봉고캣은 "켜두기만 해도 고양이가 곁에 있다"는 감성으로 10만 명 이상을 모았다.
핵심은 귀여움이 아니라 **'함께함'** — 친구의 키보드 입력이 실시간으로 시각화되어,
말 한마디 없이도 "저 친구도 지금 열심히 하고 있구나"라는 유대감을 만든다.
본 서비스는 이 경험을 모바일로 옮긴다. PC의 "화면 구석"에 해당하는 모바일의 공간은
**잠금화면**이다.

### 1.2 핵심 가치

1. **방치형 힐링** — 조작 없이 켜두기만 해도 고양이들이 살아 움직인다.
2. **커뮤니티(함께함)** — 친구의 고양이가 내 화면에 살고, 친구의 활동이 실시간으로 보인다.
3. **수집과 표현** — 시간과 상호작용이 아이템으로 보상되고, 꾸민 모습이 친구에게도 보인다.

### 1.3 타깃 사용자

- 고양이·힐링 콘텐츠를 좋아하는 10~30대
- 친구/연인/스터디 그룹 등 "느슨한 연결"을 원하는 소규모 그룹 (방 최대 인원 제한 없음, 권장 2~6명)

```
└─────────────────────────┘
```

## 3. 핵심 기능 명세

### 3.1 고양이 행동 시스템 (자율 AI)

각 고양이는 상태머신으로 자율 행동한다. 상태가 끝나면 아래 확률로 다음 행동을 고른다.

| 상태 | 확률 | 지속 시간 | 연출 |
|---|---|---|---|
| 걷기 | 38% | 1.5~4초 | 좌우 이동 + 몸통 바운스, 화면 끝에서 방향 전환 |
| 봉고 연주 | 30% | 1.5~3.5초 | 양 앞발 교차 두드림 |
| 휴식 | 32% | 2~5초 | 숨쉬기 애니메이션 |

- 친구(원격) 고양이는 **친구가 실제로 폰을 쓰는 동안** 봉고 연주 상태가 우선된다 (75%).
- 이름표: 내 고양이 "내 봉고캣", 원격 친구 "이름 · 폰 사용 중 ⌨️ / 접속 중 🟢".

### 3.2 터치 인터랙션

| 입력 | 반응 | 보상 |
|---|---|---|
| 고양이 짧게 탭 | 점프 + 이모티콘 말풍선 (보유 이모티콘 팩에서 랜덤) | 25회마다 아이템 드랍 |
| 고양이 길게 누르기(0.42초~) | 쓰다듬기: 하트 파티클 + "그르릉…" + 행복한 눈(^^) | 코인 +1 |
| 빈 화면 터치 | 내 고양이 봉고 연주 2초 (PC판 키 입력의 모바일 번역) | 멀티플레이 시 활동 신호 전파 |
| 위로 스와이프 / 하단 버튼 | 시트 열기 | — |

### 3.3 수집 시스템 (가챠)

**드랍 트리거**
- 시간 보상: 40초마다 1회 (데모 가속치 — 실서비스 권장 10~30분)
- 상호작용 보상: 내 고양이 탭 25회마다 1회
- 첫 실행 5초 후: 첫 만남 선물 1회

**희귀도 테이블**

| 등급 | 획득 확률 | 판매가(중복) | 장터 구매가 | 색상 |
|---|---|---|---|---|
| 커먼 | 60% | 5코인 | 10코인 | 회색 |
| 레어 | 25% | 20코인 | 40코인 | 파랑 |
| 에픽 | 12% | 60코인 | 120코인 | 보라 |
| 레전더리 | 3% | 250코인 | 500코인 | 금색 (전용 글로우 연출) |

> 원작은 레전더리가 1/500,000 수준. 프로토타입은 체감을 위해 가속했으며,
> 실서비스에서는 서버 확률 테이블로 이전하고 확률을 공시한다.

### 3.4 아이템 카탈로그 (총 21종)

| 분류 | 개수 | 효과 | 예시 |
|---|---|---|---|
| 모자 | 10종 | 고양이 머리에 착용, 친구 화면에도 표시 | 야구모자(커먼) ~ 황금왕관(레전더리) |
| 고양이 스킨 | 7종 | 털색 변경 | 하양냥(기본) ~ 황금냥(레전더리) |
| 이모티콘 팩 | 4종 | 탭 반응 이모티콘 풀에 추가 | 음표팩, 간식팩, 반짝팩, 보석팩 |

### 3.5 꾸미기 & 프리셋

- 착용: 모자 1개 + 스킨 1개. 착용 즉시 잠금화면과 **친구 화면의 내 고양이에 실시간 반영**.
- 프리셋: 현재 조합(모자+스킨)을 최대 4개 저장, 원터치 적용. 보유하지 않게 된 아이템은 적용 차단.

### 3.6 장터 (경제 순환)

- **오늘의 매물**: 전체 카탈로그에서 매일 4종 고정 샘플링, 구매가 = 기준가 × 2.
- **중복 판매**: 2개 이상 보유한 아이템만 판매 가능(마지막 1개는 보호), 판매가 = 기준가.
- **코인 획득 경로**: 초기 지급 30 / 쓰다듬기 +1 / 중복 판매.
- 순환 구조: `방치·터치 → 아이템 → (중복)판매 → 코인 → 원하는 아이템 구매 → 꾸미기 → 친구에게 자랑`

### 3.7 실시간 멀티플레이

**구조**: 서버 구축 없이 공개 MQTT 브로커(WebSocket)를 중계로 사용하는 방(room) 모델.

```
[내 폰] ──┐                       ┌── [친구 폰]
          ├──> MQTT 브로커 (방 토픽) <──┤
[친구 폰] ─┘   bongocat-mobile/v1/room/{코드}
```

**참가 흐름**
1. A가 "새 방 만들기" → 5자리 코드 생성 (예: `X5GE7`)
2. A가 "초대 링크 보내기" → `…github.io/-/?room=X5GE7` 를 카톡 등으로 공유
3. B가 링크를 열면 자동 참가 → 양쪽 화면에 서로의 고양이 등장

**메시지 프로토콜** (JSON)

| 이벤트 | 발생 시점 | 상대 화면의 효과 |
|---|---|---|
| `hello` / `state` | 입장 시 / 25초 하트비트 | 멤버 등록, 이름·꾸미기 동기화 |
| `activity` | 화면 사용 시작/종료 (엣지 트리거, 6초 무입력 시 종료) | 내 고양이가 봉고 연주 + "폰 사용 중 ⌨️" |
| `emote` | 자기 고양이 탭 | 내 고양이가 같은 이모티콘 말풍선 |
| `outfit` | 아이템 착용 변경 | 즉시 모자/스킨 반영 |
| `bye` | 퇴장 (last-will로 앱 강제종료도 감지) | 고양이 퇴장 |

- 오프라인 판정: 하트비트 70초 미수신 시 자동 제거.
- 브로커 이중화: 기본 브로커 접속 실패 시 10초 후 예비 브로커로 자동 전환.
- 방 미참가 시에는 **데모 친구**(가상 고양이 2마리)가 화면을 채워 첫 경험이 쓸쓸하지 않게 한다.

### 3.8 답장 없는 안부 — 쓰다듬기 & 방명록

동물의 숲의 "이웃"과 "게시판"을 벤치마킹한 비동기 연결 장치. 핵심 원칙은
**응답 의무가 없는 연결** — 흔적에는 읽음 표시도, 답장 버튼도, 푸시 알림도 없다.

- **주민 명부(roster)**: 마을(방)에 한 번 들어온 친구는 기기에 기록되어,
  접속을 끊어도 고양이가 **"자리 비움 💤"** 상태로 화면에 남는다 (채도 낮춤, 주로 휴식).
- **쓰다듬기 전달**: 친구 고양이를 꾹 눌러 쓰다듬으면 —
  - 친구가 접속 중이면 즉시: 친구 화면의 고양이가 기뻐하고 "○○가 쓰다듬어줬어요 🐾"
  - 자리 비움이면 **부재중 흔적**으로 저장(브로커 retained 우편함 `room/{코드}/mail/{받는이}/{보낸이}`),
    친구가 돌아왔을 때 전달: "○○가 다녀갔어요 🐾"
- **방명록**: 받은 흔적이 누적되는 공간. 같은 사람의 반복 흔적은 10분 단위로 ×N 표기, 최근 30개 보관.
- **자동 재입장**: 앱을 다시 열면 마지막 마을에 자동 입장 — 마을이 상시 공간이 된다.
- 스팸 방지: 같은 고양이에게 10초에 1회만 전달.

### 3.9 이름 시스템

- 기본값 "집사+숫자", 친구 탭에서 변경 (최대 8자). 모든 멀티플레이 메시지에 실려 전파된다.

## 5. 기술 구성

| 레이어 | 선택 | 이유 |
|---|---|---|
| 프런트엔드 | 순수 HTML/CSS/JS (프레임워크 없음) | 초경량, 빌드 불필요, 로딩 1초 미만 |
| 고양이 렌더링 | 인라인 SVG + CSS 애니메이션 | 해상도 무관 선명, 저전력 |
| 실시간 통신 | MQTT over WebSocket (mqtt.js 내장) | 무서버·무가입, 모바일 재접속에 강함 |
| 설치/오프라인 | PWA (manifest + Service Worker) | 홈 화면 설치 → 전체화면, 오프라인 실행 |
| 저장 | localStorage | 프로토타입 범위에 충분 |
| 배포 | GitHub Pages + GitHub Actions | 푸시하면 자동 배포, 무료 HTTPS |

```
파일 구조
├─ index.html            잠금화면 + 시트 마크업
├─ css/style.css         스타일/애니메이션 전체
├─ js/app.js             고양이 AI, 인터랙션, 가챠, 장터, UI
├─ js/multiplayer.js     실시간 방 동기화 모듈
├─ js/vendor/mqtt.min.js MQTT 클라이언트 (내장)
├─ manifest.webmanifest / sw.js / icon.svg   PWA
└─ .github/workflows/pages.yml   자동 배포
```

## 6. 제약사항 및 리스크

| 항목 | 내용 | 대응 |
|---|---|---|
| 진짜 잠금화면 불가 | 웹 기술은 OS 잠금화면을 대체할 수 없음 | PWA 전체화면으로 유사 경험 제공, 네이티브 포팅 로드맵 (7장) |
| 공개 브로커 보안 | 방 코드를 아는 누구나 입장 가능, 메시지 평문 | 프로토타입 한정. 실서비스는 자체 브로커 + 토큰 인증 |
| 공개 브로커 가용성 | 무료 공용 인프라라 SLA 없음 | 예비 브로커 자동 전환 구현됨. 실서비스는 자체 인프라 |
| 데이터 이전 불가 | 기기 저장(localStorage)이라 계정 이동 불가 | 실서비스에서 계정/서버 인벤토리 도입 |
| 화면 꺼짐 | 모바일 브라우저는 화면이 꺼지면 실행 중단 | Wake Lock API 적용 검토 (배터리 주의 고지 필수) |
| 데모 수치 | 드랍 주기·확률이 체감용으로 가속됨 | 밸런스 시트를 서버 설정값으로 분리 |

## 7. 향후 로드맵

### Phase 1 — 지금 (완료)
PWA 프로토타입: 잠금화면, 고양이 AI, 터치 반응, 가챠/꾸미기/장터, 실시간 멀티플레이, 자동 배포.

### Phase 2 — 리텐션 강화
- Wake Lock(화면 유지) + 저전력 모드(프레임 제한)
- 출석/함께한 시간 통계, 방별 "오늘 함께 있었던 시간" 표시
- 이모티콘 직접 선택 팔레트, 고양이 쓰다듬기 상호작용을 친구 고양이에게도

### Phase 3 — 서버 도입
- 계정(소셜 로그인) + 서버 인벤토리 → 기기 이전, 부정 방지
- 자체 실시간 서버(WebSocket) + 방 인증
- 유저 간 실거래 장터 (등록/구매 트랜잭션, 수수료)

### Phase 4 — 네이티브 (진짜 잠금화면)
- **Android**: `WallpaperService` 라이브 배경화면으로 잠금화면+홈에 상주
- **iOS**: WidgetKit 잠금화면 위젯(주기 갱신) + Live Activity(친구 활동 표시) + 앱 내 스탠바이 모드
- 코어 로직(행동 AI, 밸런스)은 본 프로토타입을 스펙으로 포팅

### 수익화 아이디어 (검토)
- 시즌 한정 모자/스킨 (직접 판매)
- 장터 거래 수수료
- 광고 시청 시 드랍 부스트 (강요 없는 선택형)
