# 잘지냥 디자인 고도화 가이드 — 고양이·배경을 예쁘게 바꾸는 법

> 지금 앱의 모든 그림(고양이, 모자, 책상)은 이미지 파일이 아니라 **코드로 그린 도형(SVG)**
> 이에요. 그래서 "그림 파일을 어디에 넣으면 되나요?"의 답이 단계마다 다릅니다.
> 아래 3단계 중 원하는 수준을 고르면 됩니다.

## 지금 그림이 있는 곳 (현재 구조)

| 무엇 | 파일 | 바꾸면 생기는 일 |
|---|---|---|
| 고양이 몸/표정 | `mobile/src/components/CatSvg.tsx` | 모든 고양이 모양이 바뀜 |
| 모자·목 장식·책상 소품 | `mobile/src/components/ItemAssets.tsx` | 아이템 24종의 그림 |
| 색·톤 (벽/바닥/칠판/털색) | `mobile/src/theme.ts` | 앱 전체 색감 |
| 교실 배치·책상 | `mobile/src/components/Seat.tsx`, `screens/ClassroomScreen.tsx` | 무대 레이아웃 |
| 개봉 연출·사물함 그림 | `mobile/src/screens/LockerSheet.tsx` | 가챠 화면 |

## 레벨 1 — 지금 방식(코드 SVG) 그대로 다듬기 · 비용 0원

- **Figma**(무료)에서 고양이를 그린 뒤 **SVG로 내보내기** → 그 path 좌표를
  Claude Code에게 주면서 "CatSvg.tsx의 고양이를 이걸로 교체해줘"라고 하면 됩니다.
- 장점: 용량 0에 가깝고, 털색 바꾸기(색만 갈아끼움)·아이템 겹치기가 지금 구조 그대로 동작.
- 단점: 아주 부드러운 곡선/질감 표현엔 한계.
- **색감만 바꾸는 건 5분 일**: `theme.ts`의 색 값만 바꾸면 앱 전체 무드가 바뀝니다.

## 레벨 2 — 그림 파일(PNG)로 교체 · 디자이너/AI 그림 활용

일러스트레이터에게 의뢰하거나 AI 이미지 생성으로 뽑은 그림을 쓰는 방법.

- **핵심 규칙: 레이어를 나눠서 받으세요.** 고양이 1장짜리 완성본이 아니라
  ① 몸(색별 3장) ② 표정(뜬눈/감은눈) ③ 모자들 ④ 목 장식들 — 이렇게 **투명 배경
  PNG로 분리**해서 받아야 아이템 조합이 가능합니다 (안 나누면 3색×3상태×아이템 24종
  = 수백 장을 그려야 해요).
- 파일은 `mobile/assets/cat/` 폴더에 넣고, Claude Code에게 "CatBody를 이 PNG 레이어
  겹치기로 바꿔줘"라고 하면 됩니다 (해상도는 @2x 기준 한 벌이면 충분).
- **배경이 가성비 최고**: 교실 배경 일러스트 1장(1170×2532px 세로)만 넣어도 앱 인상이
  확 달라집니다 — `ClassroomScreen`에 ImageBackground로 끼우는 건 10분 일.
- AI로 뽑을 때 일관성 팁: 첫 장을 확정한 뒤 "같은 캐릭터로 눈 감은 버전/뛰는 버전"처럼
  **캐릭터 시트**를 요청하고, 스타일 문구(예: "flat pastel sticker style, thick outline")를
  모든 프롬프트에 고정하세요.

## 레벨 3 — 전문 애니메이션 (부드러운 움직임) · 정식 출시급

- **Rive** (rive.app, 무료 시작): 게임에 최적. 에디터에서 고양이를 그리고
  **상태 머신**(idle↔walking↔active 전환)을 직접 만들면, 앱에서는 상태 이름만
  바꿔주면 됩니다. 지금 우리 구조(state 3종)와 정확히 맞아요. `rive-react-native`로 연동.
- **Lottie**: After Effects/Figma에서 만든 애니메이션을 JSON으로 내보내 재생.
  반복 재생 연출(개봉 팡파레 등)에 좋음. `lottie-react-native`.
- 추천: 캐릭터는 Rive, 이펙트(개봉 연출·하트)는 Lottie.

## 추천 진행 순서 (돈·시간 아끼는 길)

1. **theme.ts 색감 실험** (0원, 오늘 가능) → 원하는 무드 찾기
2. **교실 배경 일러스트 1장** 교체 → 인상 급상승
3. 고양이 **idle 1장**으로 그림체 확정 (AI든 외주든) → 마음에 들면
4. 상태 3종 × 색 3종 레이어 세트 + 아이템 순서로 확장
5. 반응이 좋으면 그때 Rive로 이관 (MVP 검증 전에 하기엔 과투자)

어느 단계든 그림 파일만 준비되면, 코드 교체는 Claude Code에게 맡기면 됩니다.
