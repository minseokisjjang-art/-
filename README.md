# 🐹 햄스터 목장 (Hamster Ranch)

> v1.2에서 테마를 고양이(봉고캣)에서 **햄스터 목장**으로 피벗했습니다.
> 가만히 있으면 노트북을 두들기고, 화면을 누르고 있거나 친구가 활동 중이면 챗바퀴를 굴립니다.
> 서버(목장) 로비에서 여러 목장을 만들고 전환할 수 있습니다. 아래 문서의 일부 표현은 초기 버전 기준입니다.

PC용 봉고캣의 감성을 모바일로 옮긴 **잠금화면 방치형 고양이** 프로토타입입니다.
설치 없이 브라우저에서 바로 동작하는 PWA이며, 홈 화면에 추가하면 전체화면 앱처럼 실행됩니다.

## 📱 모바일 앱 (`mobile/`) — 브리프 v2 1단계 구현

`docs/MVP-BRIEF-v2.md`의 1단계(1인용 Expo 앱)를 구현한 React Native(Expo) 버전입니다.
PWA의 행동 AI를 고양이 테마로 포팅했으며, 무대는 **교실**입니다.

- **교실 인터페이스**: 칠판(시계 + 점수판) / 나무 바닥 / 교탁 / 학생 책상
- **칠판 점수판**: 모든 고양이의 점수 칸이 실시간으로 올라감 — **점수 = 걸음 ＋ 타이핑**.
  친구(Supabase) 연동 전까지는 데모 친구 2명(민지·준호)이 학생 자리를 채움
- **고양이 자율 행동**: 어슬렁 / 제자리 필기 / 두리번 / (2분 조용하면) 낮잠
- **타이핑 반응**: 입력하는 동안 고양이가 교탁으로 걸어가 앉아서 필기 ✍️
- **걸음수 반응**: 걸음이 감지되면 일어나서 신나게 걸어다님 👟
  - iOS: 오늘 하루 누적 (expo-sensors / CMPedometer)
  - Android: 앱 실행 중 라이브 카운트 (하루 누적은 다음 단계인 Health Connect에서)
  - 웹·센서 미지원: "＋100 산책" 시뮬레이션 버튼
- **터치 반응**: 탭 → 폴짝 + 이모티콘, 길게 누르기 → 쓰다듬기(그르릉)
- **🌙 스탠바이 모드**: 화면이 꺼지지 않는 밤 풍경 + 큰 시계 (expo-keep-awake).
  폰을 세워두면 잠금화면처럼 쓰는 모드 — 진짜 OS 잠금화면 제약은 아래
  "프로토타입의 한계" 참조 (iOS는 서드파티 라이브 애니메이션 불가,
  Android는 네이티브 라이브 배경화면 필요)

실행 방법:

```bash
cd mobile
npm install
npx expo start
# 폰에 Expo Go 앱 설치 → 같은 와이파이에서 QR 스캔
# 또는 브라우저 확인: npx expo start --web
```

## 컨셉

> 봉고캣의 핵심은 **'함께함'** — 조작 없이 켜두기만 해도 고양이가 곁에 있고,
> 친구의 활동이 실시간으로 시각화되어 말 없이도 유대감을 느낄 수 있다.

리서치에서 뽑은 핵심 가치와 구현 매핑:

| 봉고캣(PC)의 핵심 | 모바일 버전 구현 |
|---|---|
| 방치형 — 켜두기만 해도 됨 | 잠금화면(시계+배경)에서 고양이들이 알아서 돌아다니고 봉고를 두드림 |
| 키보드 입력 → 고양이가 두드림 | **화면 터치 → 내 고양이가 봉고 연주** (입력의 모바일 번역) |
| 멀티플레이 — 친구 고양이가 내 화면에 | **진짜 실시간 멀티플레이**: 방을 만들어 초대 링크를 보내면 서로의 고양이가 상대 화면에 등장. 상대가 폰을 만지는 동안 상대 고양이가 실시간으로 봉고 연주 |
| 이모티콘 간접 대화 | 내 고양이를 탭하면 친구 화면의 내 고양이도 같은 이모티콘 말풍선을 띄움 |
| 수집 — 시간/입력으로 아이템 획득 | 40초마다 + 터치 25회마다 가챠 드랍 (커먼 60% ~ 레전더리 3%, 데모용 가속) |
| 꾸미기 — 모자가 백미 | 모자 10종 · 스킨 7종 · 이모티콘 팩 4종, **프리셋 저장/한 번에 적용** |
| 새 아이템이 친구 화면에도 즉시 반영 | 착용 시 반영 안내 (실서비스는 실시간 동기화) |
| 장터 — 유저 간 거래 | 중복 아이템 판매 + 오늘의 매물 구매 (코인 경제) |

여기에 모바일만의 상호작용을 더했습니다:

- **탭**: 고양이가 폴짝 뛰며 이모티콘 말풍선 (보유한 이모티콘 팩이 반응 풀에 추가됨)
- **길게 누르기**: 쓰다듬기 — 하트가 흩날리고 "그르릉…" (보상으로 코인 +1)
- **위로 스와이프**: 꾸미기/친구/장터 시트 열기

## 실행 방법

정적 파일이라 아무 웹서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# 휴대폰 브라우저에서 http://<PC IP>:8000 접속
```

모바일 브라우저에서 **"홈 화면에 추가"** 하면 상태바 없는 전체화면(fullscreen) 앱으로 실행되어
잠금화면에 가장 가까운 경험이 됩니다. 서비스워커가 오프라인 캐시를 담당합니다.

## 파일 구성

```
index.html          잠금화면 + 하단 시트 마크업
css/style.css       잠금화면/고양이 애니메이션/시트 스타일
js/app.js           고양이 행동 AI, 터치 반응, 가챠, 친구 시뮬레이션, 장터
manifest.webmanifest / sw.js / icon.svg   PWA (홈 화면 설치, 오프라인)
```

상태(코인, 인벤토리, 착용, 프리셋, 친구)는 `localStorage`에 저장됩니다.

## 프로토타입의 한계와 실서비스 로드맵

### 1. 진짜 잠금화면에 올리려면 (네이티브)

웹 기술로는 OS 잠금화면을 대체할 수 없습니다. 실제 제품화 경로:

- **Android**
  - `WallpaperService`(라이브 배경화면): 잠금화면+홈 화면 배경에서 고양이가 살아 움직이는 가장 정석적인 방법. 터치 이벤트 수신 가능(홈 화면 한정).
  - 잠금화면 위젯(Android 15+ `Glanceable Hub`) 또는 AOD는 제약이 커서 배경화면 방식 권장.
  - 이 저장소의 행동 AI/아이템 모델을 Kotlin으로 포팅.
- **iOS**
  - 잠금화면 실시간 애니메이션은 서드파티에 비허용. 대안: **잠금화면 위젯**(WidgetKit, 정적 스냅샷 주기 갱신) + **라이브 액티비티**(친구 활동 상태 표시) + 앱 내 전체화면 "스탠바이 모드".
- 공통: 배터리 보호를 위해 화면 꺼짐 감지 시 루프 중단, 저사양 모드(프레임 제한) 제공.

### 2. 실시간 멀티플레이 (구현됨)

`js/multiplayer.js` — 공개 MQTT 브로커(WebSocket)를 통한 방 기반 동기화. 서버 구축 없이 동작한다.

- 방 = 5자리 초대 코드. `?room=CODE` 링크로 원터치 참가.
- 이벤트: `hello`/`state`(입장·하트비트 25초), `activity`(화면 사용 시작/종료 엣지 트리거),
  `emote`(이모티콘), `outfit`(꾸미기 변경 즉시 반영), `bye`(퇴장, MQTT last-will로 비정상 종료 커버).
- 브로커 장애 시 예비 브로커로 자동 전환 (`BROKERS` 목록), `?broker=` 파라미터로 자체 브로커 지정 가능.
- 한계: 공개 브로커라 암호화된 인증이 없음(코드를 아는 사람은 입장 가능). 정식 서비스에서는
  자체 브로커 + 토큰 인증 또는 WebSocket 서버로 이전 권장.

### 3. 장터 실거래

- 서버 사이드 인벤토리 + 매물 등록/구매 트랜잭션. 현재 코인 경제와 희귀도별 기준가(`RARITIES[].value`)를 시드로 사용.

## 데모용 수치

체감을 위해 가속해두었습니다. 실서비스 튜닝 포인트:

- 드랍 주기 40초 (실서비스: 수 분~수십 분)
- 레전더리 3% (원작은 1/500,000 급 — 서버 확률 테이블로 이전)
